## 2024-05-18 - [Custom Selector Focus States]
**Learning:** Custom UI selectors built with multiple independent `<button>` elements (like LanguageSwitcher, StudioModeSwitch, and Tabs) can easily become inaccessible via keyboard if they rely entirely on visual cues (like background color changes) without native focus outlines. Grouping them with `role="group"` and `aria-label` provides necessary context to screen readers, while explicit `focus-visible:ring` utilities are essential for visual keyboard navigation.
**Action:** When implementing custom toggle button groups or tab selectors, always verify keyboard navigation. Wrap the group in a div with `role="group"` and a descriptive `aria-label`. Apply `focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-white/50` (or similar contrast-appropriate ring) to each individual interactive button within the group.
