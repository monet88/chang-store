## 2024-06-18 - [React Context Re-render Optimization]
**Learning:** Found multiple un-memoized Context provider values (`LanguageContext`, `ImageViewerContext`, `ApiProviderContext`) which cause unnecessary re-renders of all consumer components when the provider re-renders.
**Action:** Always wrap the `value` object passed to React Context Providers with `useMemo` and setter functions with `useCallback` to preserve object identity and prevent massive, cascading re-renders across consumers. Ensure no unintended dependency changes (`package.json`, `pnpm-lock.yaml`) are included when submitting.
